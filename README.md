# Fringe Science

A single-page web app for tracking niche, non-traditional bio-science internships in the UK (genomics, mycology, clinical research, health data) instead of the usual grad schemes.

Open `fringescience.html` in Chrome or Edge (keep `hero.mp4` next to it).

- **Dashboard**: stats and upcoming deadlines
- **Internships**: searchable list of UK programs
- **Applications**: pipeline tracker (Prep essay → Submitted → Interview → Offer), saved in your browser
- **Interview prep**: Q&A cards, a practice coach chat, and voice practice with live transcription (Web Speech API) and facial expression reading (face-api.js)

Program deadlines and pay are sample estimates. Check each program's official site before applying.
